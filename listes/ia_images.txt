# FORMAT (identique pour tous les fichiers du dossier listes/)
#   - Un site par ligne, en minuscules, SANS « https:// » ni « www. ».
#   - « exemple.com » bloque aussi tous ses sous-domaines (chat.exemple.com...).
#   - « exemple.com/chemin » bloque seulement ce chemin et ce qui est dessous.
#   - Une ligne commençant par # est un commentaire. Les lignes vides sont ignorées.
#   - Pas de joker (*) : le script ignore les lignes mal formées (et le note au journal).
#   - Le script refuse de bloquer certains domaines partagés (google.com, microsoft.com,
#     github.com...) même s'ils figurent ici par erreur. Pour bloquer un service qui vit
#     sur un tel domaine, indiquez son sous-domaine précis (ex. gemini.google.com).
#

# supprimez la ligne ou mettez # devant.
